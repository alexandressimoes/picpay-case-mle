## Submissão

Formato de Submissão do Desafio
A submissão do desafio deverá ser efetuada por meio de um repositório Git (GitHub, GitLab ou
Bitbucket). Requisitos de Submissão:

- O repositório deve ser público, assegurando o acesso para fins de avaliação.
- O link do repositório deve ser encaminhado conforme as diretrizes do processo seletivo.
- A totalidade do código necessária para a execução e avaliação deve estar versionada no repositório.

### Conteúdo Mínimo Requerido no Repositório
O repositório deverá conter, minimamente:
1. Parte 1 - Análise de Dados
    - Um arquivo notebook.py ou notebook (.ipynb) compreendendo:
    - Extração dos dados da PokeAPI.
    - Construção das tabelas especificadas.
    - Resolução das análises propostas com a utilização do Spark.
2. Parte 2 - Microsserviço
    - Código-fonte do microsserviço de análise de texto (NER).
    - Implementação da API em conformidade com o que foi detalhado no enunciado.
    - Arquivos essenciais para a execução do serviço (e.g., Dockerfile, requirements.txt ou equivalente).
3. Documentação
    - Um arquivo README.md localizado na raiz do repositório explicando a estrutura do
projeto.
